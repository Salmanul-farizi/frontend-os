# JavaScript Knowledge Domain

## Purpose
To standardize the logic, interactivity, and module structure of client-side code in Frontend OS.

## Scope
Defines how JavaScript should be written, organized, and executed in the browser.

## What Belongs Here
- Module imports/exports
- State management principles
- DOM selection and manipulation rules
- Event delegation and debouncing

## What Does NOT Belong Here
- Animation logic via GSAP (see Motion)
- Specific WordPress/Webflow JS APIs (see WordPress/Webflow)

## Relationships
- Supplements **HTML** and interfaces closely with **Motion**.
