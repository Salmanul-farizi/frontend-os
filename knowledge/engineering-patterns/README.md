# Engineering Patterns Domain

## Purpose
To document overarching architectural decisions and standard operational procedures for codebases.

## Scope
Covers folder structures, build tools, state management architecture, and overall project blueprints.

## What Belongs Here
- Project scaffold structures
- Build tool (Vite, Webpack) configurations
- Architectural paradigms (e.g., Jamstack approaches)

## What Does NOT Belong Here
- Component-level specifics (see Component Patterns)

## Relationships
- Governs the macro-structure that organizes all other domains.
