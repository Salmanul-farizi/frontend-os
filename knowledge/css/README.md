# CSS Knowledge Domain

## Purpose
To define scalable, maintainable, and performant styling rules for Frontend OS projects.

## Scope
Covers SCSS/CSS architecture, variables, mixins, and general styling conventions.

## What Belongs Here
- Naming conventions (BEM or utility combinations)
- Z-index management
- CSS Variables strategy
- Specificity rules and resets

## What Does NOT Belong Here
- Motion/Animation (see Motion)
- Media queries and breakpoints strategy (see Responsive)
- Structural layout logic strictly tied to patterns (see Component Patterns)

## Relationships
- Depends heavily on the **HTML** structure.
- Often integrates with **Responsive** guidelines.
