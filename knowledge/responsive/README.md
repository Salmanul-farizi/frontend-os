# Responsive Knowledge Domain

## Purpose
To ensure every Frontend OS project adapts flawlessly to all screen sizes and devices.

## Scope
Covers breakpoints, fluid typography, flexible grids, and mobile-first methodologies.

## What Belongs Here
- Breakpoint standards
- Fluid layout techniques (clamp, vw)
- Responsive images (`srcset`, `<picture>`)
- Touch target sizing

## What Does NOT Belong Here
- Core visual styling (see CSS)
- Complex animation responsive logic (see Motion)

## Relationships
- Intersects strongly with **CSS** and **HTML**.
