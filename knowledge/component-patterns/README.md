# Component Patterns Domain

## Purpose
To document the structural layout and styling architecture of highly reusable UI pieces.

## Scope
Covers common components like Hero sections, Cards, Tabs, and Carousels.

## What Belongs Here
- Required HTML nesting for stability
- Defensive CSS rules for variable content
- Scalability considerations

## What Does NOT Belong Here
- Micro-interactions (see Interaction Patterns)

## Relationships
- Combines **HTML** and **CSS** into robust building blocks.
