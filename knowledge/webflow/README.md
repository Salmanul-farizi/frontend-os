# Webflow Knowledge Domain

## Purpose
To standardize the translation of Frontend OS designs and code into Webflow.

## Scope
Covers Webflow classes, custom code embedding, CMS collections, and interactions.

## What Belongs Here
- Class naming mapping (Client-First, etc.)
- Webflow CMS limitations and workarounds
- Custom JavaScript integration inside Webflow

## What Does NOT Belong Here
- Core CSS principles not applicable to visual builders

## Relationships
- The integration layer specific to Webflow projects.
