# HTML Knowledge Domain

## Purpose
To standardize the structural foundation of all web experiences in Frontend OS.

## Scope
Defines the rules, best practices, and standards for writing HTML markup.

## What Belongs Here
- Semantic tag usage (e.g., `<article>`, `<section>`, `<nav>`)
- Form structure
- Document outlines (heading hierarchy)
- Data attributes and structural standards

## What Does NOT Belong Here
- Styling (CSS)
- Behavior (JavaScript)
- CMS-specific HTML structures (WordPress/Webflow)

## Relationships
- Forms the foundation for **CSS** and **Accessibility** domains.
