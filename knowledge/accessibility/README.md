# Accessibility Knowledge Domain

## Purpose
To ensure all Frontend OS products are usable by people with varying abilities.

## Scope
Covers WCAG compliance, screen reader support, keyboard navigation, and ARIA usage.

## What Belongs Here
- ARIA attribute rules
- Focus trapping and management
- Color contrast requirements
- Reduced motion guidelines

## What Does NOT Belong Here
- Basic semantic HTML that provides accessibility by default (see HTML)

## Relationships
- Modifies and augments **HTML**, **CSS**, and **JavaScript**.
