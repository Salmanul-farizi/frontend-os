# Checklists

The Checklists directory contains the verification steps required before any frontend code is shipped or handed over.

**In Frontend OS, nothing ships until the checklists pass.**

## Available Checklists

1. **[Accessibility Checklist](./accessibility-checklist.md)**
   Verifies WCAG 2.1 AA compliance, keyboard navigation, and screen reader compatibility.

2. **[Responsive Checklist](./responsive-checklist.md)**
   Verifies layout integrity across Mobile, Tablet, Desktop, and Large Desktop viewports.

3. **[Performance Checklist](./performance-checklist.md)**
   Verifies Core Web Vitals optimization, asset loading, and render-blocking resources.

4. **[SEO Checklist](./seo-checklist.md)**
   Verifies on-page semantic structure, meta tags, and Open Graph data.

5. **[QA & Pre-Ship Checklist](./qa-checklist.md)**
   The final verification: cross-browser testing, console errors, and visual fidelity.

## How to Use
Whenever an AI assistant or human engineer completes an implementation task, they must consult the relevant checklist and confirm all items pass. If acting as the `QA Reviewer` or `Accessibility Reviewer`, these documents define your entire workflow.
