# Reference Analysis Framework

1. **Deconstruct the States**: Identify all possible states (default, hover, active, animating).
2. **Identify the Triggers**: What causes the state change?
3. **Measure the Motion**: Extract timing, easing, and transforms.
4. **Analyse Responsive Adaptations**: How does the behaviour change on smaller screens?
5. **Consider Accessibility**: Keyboard navigation, focus management, screen readers.
6. **Formulate Engineering Notes**: Translate the visual behaviour into technical constraints (e.g., reuse DOM, use overwrite, don't animate layout).

The goal is to convert Reference into Engineering Behaviour.
