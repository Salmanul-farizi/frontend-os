# Delivery Standard

This defines when a component is truly "done."

A component is not complete because the code works.

It is complete when:

## Visual
- [x] Pixel accurate

## Engineering
- [x] Maintainable

## Responsive
- [x] Works on all breakpoints

## Motion
- [x] Matches specification

## Accessibility
- [x] WCAG compliant

## Performance
- [x] Optimized

## CMS
- [x] Ready

## QA
- [x] Approved
