# Task Breakdown Framework

This document defines how work is split.

Example:

Project: Healthcare Website
↓
Page: Home
↓
Section: Hero
↓
Component: Hero CTA
↓
Engineering Tasks:
- Task-001: Semantic HTML
- Task-002: SCSS Styling
- Task-003: Responsive Behaviour
- Task-004: Motion
- Task-005: Accessibility Review
- Task-006: QA

Rules:
1. One task = one responsibility.
2. Tasks should be independently executable.
3. Avoid mixing implementation concerns (e.g., HTML and JS in one task unless inseparable).
4. Components should be reusable whenever possible.
